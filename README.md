# Лабораторна робота №4

Пошук закономірностей у часових рядах: місячні відгуки Cyberpunk 2077 у Steam і обов'язковий DataSet №8 із продажами.

## Запуск

Потрібні Python 3.12+, Git та uv. Залежності зафіксовані в `uv.lock`.

Якщо uv ще не встановлено:

```shell
python -m pip install uv
```

Завантаження та повний запуск:

```shell
git clone https://github.com/Artychanal/time-series-lab-4-serkeli.git
cd time-series-lab-4-serkeli
uv sync --frozen
uv run --frozen python -B -X utf8 main.py
```

У PyCharm виберіть `.venv/Scripts/python.exe` та запустіть `main.py`. Дані й стандартна папка результатів визначаються від розташування скрипта. Після встановлення залежностей обчислення не потребують мережі.

Швидкий запуск зі збереженням результатів окремо:

```powershell
uv run --frozen python -B -X utf8 main.py --simulations 30 --output results_quick
```

Параметри: `--data`, `--output`, `--simulations` (мінімум 30), `--seed`. Повний запуск: seed 42, по 300 реалізацій двох генераторів на кожному наборі, разом 1200 синтетичних наборів. Значення за замовчуванням відповідають звіту.

## Дослідження

- Перевірка даних, логічних тотожностей та календарів; контрольні суми джерел.
- Robust STL, ковзна медіана, сила тренду й сезонності, чутливість до параметрів та релізного місяця.
- ACF/PACF, ADF/KPSS; Pearson/Spearman у рівнях, різницях і залишках, лагові зв'язки.
- KMeans і Ward, вибір кількості кластерів, silhouette, ARI, зміна масштабу, виключення об'єктів і зміна кроку часових вікон.
- Хронологічний вибір часової моделі, незалежний фінальний період і наївний прогноз.
- Узгоджена синтетика, незалежні базові генератори, порівняння властивостей та характеристик фіксованих кластерів.
- Таблиці CSV, підсумок JSON, протокол запуску та 15 графіків PNG.

## Дані та обмеження

Steam: 69 повних місяців, грудень 2020 — серпень 2026. Неповний вересень у знімку від 21.09.2026 виключено. Метадані містять URL джерела. Реальні сплески збережено. 12-місячні вікна перекриваються і не є незалежними спостереженнями.

DataSet №8: у `data/dataset8.csv` збережено 15 операцій і 10 полів, потрібних програмі, із початкових 26 колонок. Імена, адреси та інші невикористовувані відомості про клієнтів вилучено перед публікацією, номери операцій замінено послідовними номерами рядків. Дати, товари, категорії, регіони, ціни, кількості, виручку й доставку збережено. Дані охоплюють 9 дат у січні 2015 року. Заголовок згадує 2021 рік, але аналіз використовує фактичні дати рядків. Валютні коми та нерозривні пробіли обробляються завантажувачем. Відсутні календарні дати невідомі; окремий файл із нулями має явно умовний зміст. Часову сезонність на цьому наборі надійно оцінити неможливо.

На Steam модель вибирається за expanding-window валідацією: початкові 36 місяців, наступний 21 місяць — валідація, останні 12 — фінальний тест. У тесті параметри оцінено один раз на перших 57 місяцях; прогноз використовує попереднє спостереження. Декомпозиція всієї історії призначена для ретроспективного опису.

Генератори оцінюються на всій відомій історії для умовного відтворення властивостей. Інтервали 2,5–97,5% описують розкид реалізацій за фіксованих параметрів; вони не доводять відповідність генеральній сукупності. Sales-генератор використовує емпіричний каталог і частоти товарів, плавно змінює кількість/частку доставки та незалежно перевибирає дати на наявній опорі. Він не прогнозує майбутні місяці.

## Структура

`main.py` — параметри запуску; `real_analysis.py` — етапи дослідження; `data_loader.py` — адаптери даних; `decomposition.py`, `correlation_analysis.py`, `clustering.py` — методи аналізу; `synthetic_data.py` — генератори; `evaluation.py` — метрики й протоколи; `visualization.py` — графіки. `data/` містить вхідні файли.

Ключові виходи: `results/analysis_summary.json`, `steam_model_comparison.csv`, `steam_generator_effectiveness.csv`, `sales_generator_effectiveness.csv`, `*_ensemble_comparison.csv`, `*_cluster_stability.csv`, `method_applicability.csv`, `figures/`.

Вбудована верифікація перевіряє реконструкцію STL, узгодженість синтетичних кількостей і виручки та скінченність метрик. Докладні результати записуються у JSON. Слабку сезонність, нестійкість груп і випадки переваги незалежного генератора збережено в результатах.
